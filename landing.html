Download

All platforms
    “Windows protected your PC” / “Apple could not verify”?

    The beta binary is not code-signed yet (signing lands at public launch), so your OS will warn on first run:

    • Windows (SmartScreen): click More info → Run anyway.
    • macOS (Gatekeeper): right-click the app → Open → Open, or allow it under System Settings → Privacy & Security → Open Anyway.

    Every release ships a SHA256SUMS file — verify your download against it.

    Web app

    Open app.kaeva.app

    Runs in any browser — nothing to download. To keep it like a native app, use your browser’s Install option (address-bar icon in Chrome/Edge, Share → Add to Home Screen on iOS).

    CLI

    Linux & macOS

    curl -sSL install.kaeva.app | sh

    Windows (PowerShell)

    iwr -useb install.kaeva.app/install.ps1 | iex

    Reinstalling or upgrading is safe. The installer only places the unblock binary on your PATH — it never touches your ~/.unblock data, so your identity, comms, and saved state are preserved across reinstalls.
